# Tonberries Bot

A personal Discord bot for one (1) club in Umamusume — daily fan-count tracking, event notifications, and a pile of Uma Musume lookup tools.

## What it does

- **Circle tracking** — posts/updates a live dashboard of member fan counts, rank cutoffs, and monthly leaderboards, synced to the game's daily reset.
- **Event notifications** — tracks ongoing/upcoming in-game events and posts reminders.
- `/skill` — look up an Uma Musume skill's condition and effect.
- `/parent` — recommended inherited skills for a Champions Meeting.
- `/stamina` — minimum Stamina per running style for a CM or course.
- `/whenis` — when a support card or character will appear on a banner.
- `/role` / `/removerole` — self-service character fan roles (Tonberries server only).

## Status

This is a one-off bot built for a specific server — not set up for general use, and not documented for it either. If you've stumbled onto this repo, there's not much to see here 👀
